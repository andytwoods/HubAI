Turn a spare computer into a worker

The watcher checks this board every 5 seconds (no AI tokens while idle). When a task is waiting it claims it and runs Claude Code in your repo to do it, then picks up the next one. Set up the repo first: clone it, and add the Claude Code command from "Connect your AI agent" inside it.

Claude will edit files and run shell commands in that repo without asking. Only use a machine and repo you're happy to hand over to an agent.

Windows (PowerShell; needs uv):

curl.exe -o hubai_worker.py https://raw.githubusercontent.com/andytwoods/HubAI/main/worker/hubai_worker.py
$env:HUBAI_TOKEN = "{{ membership.token }}"
uv run hubai_worker.py --repo C:\path\to\your-repo --agent "$($env:COMPUTERNAME.ToLower())-worker"

macOS / Linux:

curl -o hubai_worker.py https://raw.githubusercontent.com/andytwoods/HubAI/main/worker/hubai_worker.py
export HUBAI_TOKEN="{{ membership.token }}"
uv run hubai_worker.py --repo ~/path/to/your-repo --agent "$(hostname -s)-worker"

Change the --repo path to your repo. Leave the window open; each task's log goes to ~/.hubai-worker/task-<id>.log. More options: uv run hubai_worker.py --help, or see the README.
