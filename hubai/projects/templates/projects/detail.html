Turn a spare computer into a worker

The watcher checks this board every 5 seconds (no AI tokens while idle). When a task is waiting it claims it and runs Claude Code in your repo to do it, then picks up the next one. Set up the repo first: clone it, and add the Claude Code command from "Connect your AI agent" inside it.

Check the machine first:

  1. The repo's own tests pass there. Native Windows often fails Unix-style test setups; WSL2 avoids that.
  2. Claude Code is logged in, and the repo has the HubAI command from "Connect your AI agent" added.
  3. Git can push: git push --dry-run works (e.g. after gh auth login and gh auth setup-git).
  4. On Windows, run the watcher from your desktop session, not over SSH: SSH sessions can't read saved GitHub logins.

Claude will edit files and run shell commands in that repo without asking. Only use a machine and repo you're happy to hand over to an agent. The watcher only takes tasks you created, so keep your passphrase and this token private; add trusted teammates with --trust their@email.

Windows (PowerShell; needs uv):

curl.exe -o hubai_worker.py https://raw.githubusercontent.com/andytwoods/HubAI/main/worker/hubai_worker.py
$env:HUBAI_TOKEN = "{{ membership.token }}"
uv run hubai_worker.py --repo "$HOME\PycharmProjects\your-repo" --agent "$($env:COMPUTERNAME.ToLower())-worker"

macOS / Linux:

curl -o hubai_worker.py https://raw.githubusercontent.com/andytwoods/HubAI/main/worker/hubai_worker.py
export HUBAI_TOKEN="{{ membership.token }}"
uv run hubai_worker.py --repo ~/path/to/your-repo --agent "$(hostname -s)-worker"

Change the --repo path to your repo. Leave the window open; each task's log goes to ~/.hubai-worker/task-<id>.log. More options: uv run hubai_worker.py --help, or see the README.

Keep it running after a reboot (Windows): save the three lines above as hubai-worker.cmd (use set HUBAI_TOKEN=... instead of $env:, and %USERPROFILE% instead of $HOME), then run this once to start it at every logon:

schtasks /create /tn "HubAI worker" /tr "%USERPROFILE%\hubai-worker.cmd" /sc onlogon /it /f
